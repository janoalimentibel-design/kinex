# Cierre y envío manual · v3.51

Marcar el último ejercicio guarda ese ejercicio localmente y ya no abre un
cartel ni envía datos. Al final de Hoy, «Completar entrenamiento» permite cargar
minutos de gimnasio, actividades aeróbicas y calorías. Los campos opcionales
siguen admitiendo vacío y cero sin estimaciones.

Con Drive conectado, «Guardar y enviar entrenamiento» valida y confirma el
guardado local antes de enviar la copia privada. «Guardar en este dispositivo»
permite seguir sin enviar. Sin conexión configurada, «Guardar entrenamiento»
guarda localmente. «Sensaciones y notas» conserva el formulario opcional.

Conectar, editar, reabrir, volver a tener internet y esperar no disparan envíos.
Un error de guardado impide el envío; un error de red conserva los datos locales
para reintentar. Solo se muestra enviado después de la confirmación de Drive.
Al modificar datos ya enviados se mantiene la confirmación para reemplazar la
copia anterior. No cambia el esquema de backups ni se incluye información real
en el código o las pruebas.
